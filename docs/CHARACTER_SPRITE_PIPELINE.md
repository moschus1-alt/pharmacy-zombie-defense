# Character Sprite Pipeline

## 기본 규격

- 포맷: 투명 배경 RGBA PNG
- 시트: 4행 × 4열, 권장 512×512px, 셀 128×128px
- 행 순서: 정면, 왼쪽, 오른쪽, 뒷면
- 열 순서: 기본, 왼발, 통과, 오른발
- 오른쪽 행은 왼쪽 행을 정확히 수평 반전한다.
- 모든 프레임은 같은 중심점과 발 기준선을 사용하고 머리, 손, 발, 소품이 셀 밖으로 잘리지 않아야 한다.

## 생성 프롬프트 필수 조건

- 2D 브라우저 타워 디펜스 게임용 캐릭터
- 살짝 위에서 내려다보는 정면 중심 카메라
- 정확한 4×4 프레임 배열과 투명 배경
- 각 셀 안에 전신과 장비가 완전히 들어감
- 텍스트, 로고, 워터마크 없음
- 밝고 익살스러운 약국 코미디 카툰 스타일 통일

## 게임 연결 및 검사

1. 이미지의 알파 채널, 16개 프레임, 셀 크기를 검사한다.
2. 발 기준선과 프레임별 중심 흔들림, 좌우 방향을 검사한다.
3. `idle`, `walk`, `attack`, `hurt`, `death` 상태는 게임 코드의 단일 상태 모델에서 관리한다.
4. 로컬 HTTP 서버에서 모든 방향과 상태 전환, 공격 프레임 판정, 화면 잘림을 확인한다.
